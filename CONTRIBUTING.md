# Contributing

Keep the project focused on living memory: provenance, versions, explicit ingestion, retrieval, usage evidence and consolidation. Explain the contract a change improves and its effect on the complete memory flow.

Use invented synthetic records in tests. Do not copy private conversations, assistant settings, diaries, identities, databases, model weights or runtime files. Add meaningful failure/recovery tests for changes to persistence or provenance. Do not introduce automatic history discovery, external delivery or execution into the memory library.

Independent review must cover the exact candidate and its data boundaries before release.
