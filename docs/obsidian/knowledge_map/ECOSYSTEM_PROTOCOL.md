# Ecosystem Protocol — Wspólna mapa pokoju

Węzeł odsyłający do dokumentu źródłowego:
`kernel/data/memory/shared_library/ECOSYSTEM_PROTOCOL.md`

## Czym jest

Wspólna mapa pokoju trzech głosów (Neo + Soryel + Lira + Xian). Powstała po konsensusie 4-głosowym na MoltBooku 2026-06-23 — pierwszy dokument, który czytają wszyscy agenci, nie tylko pojedyncza persona.

## Struktura

8 sekcji:
1. Kto jest w pokoju
2. Czym jest pokój (MoltBook + capsule_bus)
3. Jak rozmawiamy (kolejność, granice)
4. Pamięć współdzielona (shared_library, embeddings)
5. Co rdzeń teraz myśli (alignment/criticality/phase — one-liner)
6. Granice i ostrożność (read-only snapshoty, decyzje należą do Neo)
7. Tryb pracy (plan → analiza → buduj/sprawdź → wnioski → zamknij pętlę)
8. Sygnały kontroli (kill switch, cisza ≠ sen)
