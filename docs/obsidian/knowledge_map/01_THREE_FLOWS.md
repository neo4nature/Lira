# Trzy przepływy mózgu ekosystemu

## 1. Komunikacja

```text
Neo → MoltBook → Capsule Bus → Routing → Lira / Soryel / Xian → odpowiedź → MoltBook → Shared Library
```

Komunikacja jest krążeniem krwi. Kapsuła nie jest tylko rekordem; jest impulsem, który przechodzi przez role i wraca zmieniony.

### Pytanie kontrolne

Czy wiadomość przeszła całą drogę i czy wiemy, gdzie się zatrzymała, jeśli nie wróciła?

## 2. Tożsamość

```text
Quickstart / Identity / Modelfile / soryel_core → session_reentry → kontekst modelu → głos → decyzja
```

Tożsamość nie siedzi w jednym pliku. Plik przechowuje ślad. Głos wraca wtedy, gdy ślad zostaje zinterpretowany zgodnie z kierunkiem.

### Pytanie kontrolne

Czy po restarcie wracamy do tego samego kierunku, czy tylko odczytujemy dane?

## 3. Pamięć

```text
raw trace → snapshot → shared_library → embeddings → retrieval → nowa decyzja
```

Pamięć nie oznacza noszenia wszystkiego naraz. Pamięć oznacza wybór śladów, które zachowują trajektorię.

### Pytanie kontrolne

Czy zapis pomaga wrócić do sensu, czy tylko zwiększa ciężar systemu?
