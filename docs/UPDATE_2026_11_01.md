# November attention update — release candidate

Base public commit: `76d144a78aa63c7b6baa44741e60fa9d02cc2969` (25 October).
Status: local candidate, pending independent review. No public push performed.

Adds reviewed concept-card matching, retrieval callback composition, bounded source-backed
context rendering and an immutable shared packet/deadline store. Adds the common append
lock to the three index writers shipped in this library. Synthetic tests and a runnable
example explain the complete source-message to two-readers path.

The workshop's source checking, byte-bound reviews and shared-deadline design were
independently reviewed there. These portable adapters contain new changes and require
new review; production success in the workshop is not proof of this extraction.

Automatic concept-card creation is not included. Host inboxes, voice interfaces,
private memories, accounts and startup scripts are not included. The current story
page contains no unverified Amazon product links.

Builder verification: 86 offline tests passed. One Python multiprocessing/fork warning
occurred; it concerns the forced-interleaving test environment, not a model invocation.
The synthetic demo printed identical packet IDs and SHA-256 values for both readers.

R2 after independent review: English packet fields, explicit host channel, generic user-message wording, deduplicated rendered evidence and a three-sentence opening example. New channel/duplicate-evidence regression added.
